# Monsters of the Midnight Zone — Online Teaching Portfolio

Caroline Edmonds · GRAD 550 Final Project · Oregon State University

## Put it on GitHub Pages (about 5 minutes)

1. Sign in at github.com and click **New repository**.
   - Name it `teaching-portfolio` (or `yourusername.github.io` for the shortest URL).
   - Set it to **Public** and click **Create repository**.
2. On the new repo page, click **uploading an existing file**.
   Drag in `index.html`, `.nojekyll`, and this `README.md`, then click **Commit changes**.
   (`.nojekyll` may be hidden on your computer; it's optional, so skip it if you can't see it.)
3. Go to **Settings → Pages**. Under "Build and deployment," set Source to
   **Deploy from a branch**, Branch to **main**, folder **/ (root)**, and click **Save**.
4. Wait a minute or two, then refresh. Your link appears at the top of the Pages screen:
   `https://YOURUSERNAME.github.io/teaching-portfolio/`

## Linking to one section

Each section has its own link, e.g. `.../teaching-portfolio/#summative` or `#formative`.

## Updating

When you get a new version of `index.html`, go to the repo's main page, click
**Add file → Upload files**, drag the new file in (it replaces the old one), and commit. The site updates in a minute or two.
